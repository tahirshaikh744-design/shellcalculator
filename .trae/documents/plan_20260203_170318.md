I have analyzed the XML files and identified the issues. Many of the icons (e.g., `ic_unit_*.xml`, `ic_finance_*.xml`) have:
1.  **Incorrect Dimensions**: `android:width` and `android:height` are set to large values (e.g., 200dp, 225dp) instead of the standard `24dp`.
2.  **Inefficient Path Data**: The files contain thousands of separate `<path>` elements for the same color, resulting in huge file sizes (e.g., `ic_finance_tax.xml` is 372KB).
3.  **Redundant Attributes**: They often have `strokeWidth="1"` and `strokeColor` matching the `fillColor`, which is unnecessary and adds overhead.

I will create and run a Python script to automatically fix and optimize these files.

### Plan:
1.  **Scan**: Identify all `ic_finance_*.xml` and `ic_unit_*.xml` files in the drawable directory.
2.  **Process**: For each file:
    - Update `android:width` and `android:height` to `24dp`.
    - **Optimize Paths**:
        - Merge adjacent `<path>` elements that share the same attributes (color, stroke, etc.) into a single `<path>` to drastically reduce file size.
        - Remove redundant `stroke` attributes if the stroke color matches the fill color.
3.  **Verify**: Check the file size and content of a processed file to ensure correctness.
